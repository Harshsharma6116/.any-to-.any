.anyto.any

Convert documents, spreadsheets, slides and text between formats. When a file has tables, you can remove columns or rows before you convert. Files stay in your browser.

1. Add a file

Word, PDF, Excel, PowerPoint, CSV, Markdown, HTML, JSON or text.

Drop a file hereor pick one from your device

Reads .docx .pdf .xlsx .xls .ods .pptx .csv .tsv .md .html .json .txt. Older .doc and .ppt files need to be re-saved as .docx or .pptx first.

2. Choose the new format

Pick what you want to end up with.

3. Tables

Text, headings, lists and tables carry over. Images, fonts and page layout do not.
